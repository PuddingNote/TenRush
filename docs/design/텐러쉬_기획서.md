# 텐러쉬 (Ten Rush) — 게임 기획서

> 프로토타입 테스트를 거쳐 확정된 버전. 그리드 배열 연산만으로 동작하며, 물리/중력 시뮬레이션이 전혀 없는 것이 이 게임의 가장 큰 장점.

---

## 1. 한 줄 컨셉

**"더해서 10, 그거면 끝."**
6×7 그리드에서 아무 타일 두 개나 짚어서 합이 10이 되면 제거되는 초단순 매치 퍼즐.

---

## 2. 코어 조작

- 그리드 안 숫자 타일을 탭 → 선택(하이라이트)
- 다른 타일을 탭했을 때 두 값의 합이 **10**이면 즉시 제거
- 합이 10이 아니면 살짝 흔들리는 피드백 후 선택 해제, 방금 탭한 타일이 새 선택으로 이어짐 (재탭 없이 바로 다음 시도 가능)
- 인접 여부는 상관없음 — 그리드 어디에 있든 두 개만 고르면 됨

**왜 설명이 필요 없나**: "더해서 10"은 숫자를 아는 사람이면 나라/언어 상관없이 즉시 이해하는 규칙. 튜토리얼 텍스트 자체가 불필요함.

---

## 3. 확정된 핵심 로직: 제자리 리필 (테스트 후 변경)

- 초기 설계는 "타일 제거 → 위 타일이 중력처럼 아래로 당겨짐 → 빈 자리는 맨 위에서 새로 채움" 이었음
- 프로토타입 테스트 결과, **그 자리에서 바로 새 숫자로 교체**하는 방식이 더 낫다고 판단 → 최종 반영

```
매치 성공 시:
  grid[a.row][a.col] = 새로운 랜덤 숫자(1~9)
  grid[b.row][b.col] = 새로운 랜덤 숫자(1~9)
```

- **구현 관점 이점**: 컬럼 단위로 살아남은 타일을 재배치하는 로직(survivors 배열 계산, 당겨 내리기)이 통째로 사라짐. 그냥 인덱스 두 개 값만 바꾸는 것으로 끝 — Ten Match를 "구현이 가장 쉬운 후보"로 꼽았던 이유가 이번 변경으로 한 번 더 단순해짐
- **플레이 관점 이점**: 매치할 때마다 그리드 전체 배치가 흔들리지 않아서, 플레이어가 다음 짝을 계속 눈으로 스캔하고 있던 흐름이 끊기지 않음. 중력형은 화면이 계속 들썩여서 오히려 집중을 방해했던 것으로 보임
- **막힘 방지 로직도 그대로 유지**: 매치 후 그리드에 합 10 페어가 하나도 없으면 전체 리셔플

---

## 4. 진행 & 긴장감 구조 (변경 없음, 테스트에서 유지 확정)

| 요소 | 내용 |
|---|---|
| 라운드 타이머 | 60초 카운트다운, 상단 바가 시간에 비례해 줄어듦, 10초 이하부터 경고색 |
| 콤보 | 1.5초 안에 연속 매치 시 콤보 배율 상승, 매치당 기본 10점 + (콤보-1)×5점 |
| 종료 조건 | 시간 종료 시 최종 점수 표시 후 즉시 재시작 가능 |

---

## 5. 왜 설명 없이도 재밌는가 (직관성 체크)

- 규칙 이해: 즉시 (숫자 더하기)
- 실패해도 손해 없음: 오답 타일이 사라지지 않고 그대로 남아있어서 부담 없이 계속 시도 가능
- 성공 피드백: 타일이 사라지고 그 자리에 새 숫자가 바로 나타나 "다음 기회"가 즉시 주어짐 → 멈춤 없는 몰입

---

## 6. 아트 파이프라인

- 타일: 숫자 1~9, HSL 값으로 색상 자동 생성 (색상 에셋 제작 불필요, 코드로 전부 처리)
- 필요한 실제 아트 리소스: 배경, HUD 아이콘 몇 개 정도가 전부
- 컬러 반응 요소(콤보 시 색 강조, 선택 시 글로우)는 셰이더 없이 CSS/Unity UI 애니메이션 수준으로 충분히 구현 가능

---

## 7. 수익화 설계 : 나는 Google Admob밖에 안써봤으니 참고.

| 유형 | 내용 |
|---|---|
| 리워드 광고 | 타임업 후 "+15초 연장" 1회 |
| 리워드 광고 | 그리드 전체 셔플권 (막혔다고 느낄 때 사용) |
| IAP | 타일 색상 테마 팩 (파스텔, 네온, 모노톤 등 — HSL 값만 다르게 하면 되므로 원가 없음) |
| IAP | 노애드 |
| 라이트 배틀패스 | 데일리 최고 점수 기반 시즌 보상 |

---

## 8. 기술 스택 (Unity 이식 기준)

- 2D UI Grid (UGUI GridLayoutGroup 또는 단순 좌표 배치)
- 로직: `int[,] grid` 2차원 배열 + 인덱스 값 교체만으로 전체 게임 로직 완성
- 애니메이션: DOTween으로 제거 시 스케일 축소, 새 타일 등장 시 페이드인 — Rigidbody/Physics2D **완전 불필요**
- 오디오: 매치 성공 사운드 + 콤보 단계별 피치업 정도로 충분한 손맛 확보 가능

---

## 9. 구현 난이도 최종 평가

| 항목 | 평가 |
|---|---|
| 필요 물리 | 없음 |
| 핵심 자료구조 | 2차원 배열 (인덱스 값 교체만) |
| 예상 프로토타입 기간 | 2~3일 (실제로 이미 검증됨) |
| 밸런싱 변수 | 그리드 크기, 타이머 길이, 콤보 윈도우 시간, 콤보 보너스 점수 — 전부 숫자 값 조정만으로 튜닝 가능 |

3. 리워드 광고 삽입 지점(+15초 연장, 셔플권)이 실제로 유저가 원할 만한 타이밍인지 확인
